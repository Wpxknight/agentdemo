## 当前阻塞/风险

- `local` 沙箱用于开发联调，不提供容器/虚拟机级安全隔离；生产隔离仍需配置 E2B 或 OpenSandbox。
- `local` 浏览器预览是本机 Chrome 截图轮询预览和 computer-use 操作，不是生产 noVNC；生产远端桌面/VNC 仍需 E2B desktop provider 凭据后复测。
- Browser 插件未出现在当前会话可用工具中，项目也没有 Playwright 依赖；本次渲染级 UI 复测使用系统 Chrome DevTools。
- 当前附件上传通过 JSON/base64 随 agent 请求发送，适合小型图片/日志/配置文件；大文件需要后续引入对象存储或分片上传。
