# 智能助手侧边栏按钮提示设计

## 目标

在智能助手标题栏中，为左侧会话栏和右侧沙箱栏的展开/收起按钮提供清晰的悬停与键盘聚焦说明。

## 交互设计

- 左侧按钮根据当前状态显示“收起左侧会话栏”或“展开左侧会话栏”。
- 右侧按钮根据当前状态显示“收起右侧沙箱栏”或“展开右侧沙箱栏”。
- 使用项目现有 Tooltip 组件，保持与侧边导航提示一致。
- Tooltip 支持鼠标悬停和键盘聚焦，不改变按钮尺寸、图标或标题栏排版。
- 按钮的 `aria-label` 与 Tooltip 文案保持一致，便于辅助技术识别。

## 实现范围

- 修改 `PrototypeChatHeader` 的两个侧边栏切换按钮。
- 复用现有 `Tooltip`、`TooltipTrigger`、`TooltipContent`，不新增依赖或通用组件。
- 添加前端源码契约测试，并在部署环境中验证两个按钮的展开/收起文案切换。

## 验收标准

- 鼠标停留在左侧按钮时显示对应的左侧会话栏操作说明。
- 鼠标停留在右侧按钮时显示对应的右侧沙箱栏操作说明。
- 点击按钮后，提示文字会随展开/收起状态切换。
- 键盘聚焦按钮时也可看到提示。
- 标题栏尺寸、按钮尺寸及移动端布局无回归。
