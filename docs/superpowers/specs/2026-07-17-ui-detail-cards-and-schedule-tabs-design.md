# 标题指标、沙箱模板、聊天附件与定时任务详情设计

## 目标

- 缩小标题栏“上下文”和“总消耗”的字号，并使用常规字重。
- 将支持的沙箱模板改为可点击卡片，并通过居中弹窗展示完整详情。
- 将图片附件文件名放到图片下方，避免重复文件 chip。
- 将定时任务详情拆分为“任务详情”和“执行记录”两个 Tab。
- 点击单条执行记录后，用居中弹窗展示完整执行历史详情。
- 创建和编辑定时任务复用一致的字段、校验和排版，修正预批准复选框位置。

## 非目标

- 不新增沙箱模板编辑、删除或启动操作。
- 不改变后端沙箱模板数据结构。
- 不改变定时任务接口、执行逻辑或历史记录保留策略。
- 不改变非图片附件的文件 chip 行为。

## 标题栏指标

标题栏保持现有顺序：状态、运行计时、上下文、总消耗。运行中示例：

`运行中  00:23  上下文 101K/200K  总消耗 262K`

“上下文”和“总消耗”使用更小字号和常规字重；计时紧跟“运行中”右侧，继续使用等宽数字便于观察变化。移动端允许指标自然紧凑换行，但不得隐藏上下文或总消耗，也不得产生横向溢出。

## 沙箱模板卡片与详情

模板 Tab 使用响应式卡片网格。每张卡片只展示摘要信息，并确保一行只展示一个字段：

1. 模板名称与类型标签
2. 环境类型
3. 运行角色
4. Template ID

卡片整块可点击，并支持键盘 Enter/Space。悬浮、聚焦和选中反馈使用主色边框或浅背景。`特权诊断`使用非红色的琥珀或灰蓝标签。

点击卡片后打开现有风格的居中 `ModalDialog`。弹窗完整展示：描述、Template ID、镜像、环境类型、运行角色、Domain、Namespace、ServiceAccount、是否桌面环境、是否特权、能力列表和超时。缺失字段显示 `-`。

## 图片附件

图片附件使用一个独立的 figure 风格容器：

- 上部是可点击放大的缩略图。
- 下部只显示小号、弱化颜色的文件名，过长时省略。
- 编辑态删除按钮位于图片右上角，不占用文件名区域。
- 图片不再重复渲染通用附件 chip。
- 非图片附件继续显示图标、文件名、类型、大小和删除按钮。

该规则同时用于发送前的编辑态附件区和已经发送的聊天消息附件区。

## 定时任务详情 Tab

定时任务详情页保留返回按钮和页面标题，主体卡片内使用两个 Tab：

### 任务详情

- 展示任务标题、描述、计划、下次执行、启用状态和预批准状态。
- 提供立即执行、暂停/启用、编辑、删除和刷新操作。
- 编辑状态在当前 Tab 内显示共享任务表单。

### 执行记录

- 展示分页历史列表，字段为时间、状态、步骤。
- 点击整行或时间按钮打开居中弹窗。
- 弹窗展示执行时间、状态、步骤数和完整输出。
- 切换任务时关闭已打开的执行记录弹窗，并把记录页码重置为第一页。

## 创建与编辑共享表单

创建和编辑复用一个 `ScheduleTaskForm` 组件。字段顺序统一为：

1. 任务标题
2. 任务描述
3. 执行计划预设
4. cron 表达式
5. 预批准

预批准使用独立横向行：复选框固定在文字左侧，文字可换行，整行垂直居中。它不进入普通输入框的 grid 列，也不使用 `white-space: nowrap` 强制挤压。

共享表单接收初始值、禁用状态、提交文案、取消回调和字段变更回调。创建和编辑沿用各自现有提交接口及成功提示，不改变后端请求结构。

## 状态与错误处理

- 沙箱模板为空时保留空状态。
- 模板字段缺失时显示 `-`，不阻断弹窗。
- 执行记录加载失败时在记录 Tab 内显示现有错误信息。
- 执行记录没有详情时弹窗显示“暂无执行结果”。
- 图片加载失败时保留文件名，不显示重复 chip。

## 测试与验收

- 前端测试验证模板卡片结构、每行一个字段、键盘交互、居中弹窗和非红色特权标签。
- 前端测试验证图片附件不重复渲染 chip、文件名位于缩略图下方以及删除按钮位置。
- 前端测试验证定时任务两个 Tab、执行记录弹窗和共享创建/编辑表单。
- 前端测试验证预批准复选框位于独立横向行。
- 运行全量测试、类型检查和前端构建。
- 部署到 `aiop-dev`，使用 Playwright 验证桌面与移动端布局、弹窗交互、控制台和横向溢出。
