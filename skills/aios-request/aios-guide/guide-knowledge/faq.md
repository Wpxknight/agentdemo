# 高频问题速查

## 平台基础

### 平台是什么？

博云AI模型训推平台面向人工智能提供大规模智算融合深度学习训练平台，帮助客户针对自身业务场景快速定制专属大模型。平台支持数据管理、算法开发、模型训练、模型管理、推理部署等一站式模型服务。

### 平台支持哪些 AI 框架？

支持 TensorFlow、PyTorch、MPI、PaddlePaddle、MindSpore 等主流开源 AI 开发框架，也支持开发者使用自研的算法框架。

### 浏览器要求？

推荐使用 Firefox 或 Chrome 浏览器。

## 登录与项目

### 如何登录平台？

输入用户账号密码，登录系统。不同角色（平台管理员、租户管理员、平台用户）登录后看到的菜单不同。

### 如何创建/切换项目？

1. 登录后，在左上角选择项目空间
2. 如果还没有项目，需要联系租户管理员创建项目
3. 选择目标项目后即可在项目空间下操作

## 数据管理

### 如何上传数据文件？

1. 点击左侧【BMP】，点击【数据管理】，点击【文件管理】
2. 选择目标目录（用户目录/项目目录/共享目录）
3. 点击【上传】按钮上传文件

### 数据目录有什么区别？

- **用户目录**：私人目录，仅当前用户可见
- **项目目录**：项目成员共享目录，项目成员均可访问
- **共享目录**：平台级公共目录，所有用户均可见

### 如何创建数据集？

1. 点击左侧【BMP】，点击【数据管理】，点击【数据集】-【用户数据集】
2. 在左上角选择项目空间
3. 点击【创建】按钮
4. 上传数据集文件后点击【保存】

### 数据标注支持哪些方式？

支持以下标注方式：
- **手动标注**：逐条标注数据
- **协同标注**：多人协作标注
- **自动标注**：使用 AI 模型自动标注

## 模型训练

### 如何创建训练任务？

1. 点击左侧【BMP】，点击【模型训练】，点击【训练任务】
2. 点击【创建】按钮
3. 填写任务名称、选择框架/镜像、配置资源
4. 设置启动命令和数据挂载路径
5. 点击【确定】创建任务

### 训练任务需要哪些必要参数？

- 任务名称（需符合命名规范）
- 训练框架和镜像
- 启动命令
- 资源配置（GPU、CPU、内存）

## 模型推理

### 如何部署推理服务？

1. 点击左侧【BMP】，点击【推理中心】，点击【在线推理】
2. 点击【创建】按钮
3. 选择要部署的模型
4. 配置推理服务参数
5. 点击【确定】完成部署

### 推理服务部署后怎么调用？

部署成功后，可以通过以下方式调用：
- 在线预测：点击推理任务行的【预测】按钮
- API 调用：通过 API key 进行鉴权后调用推理接口
- 大模型对话：点击【体验】按钮进入对话界面

### 什么是灰度发布？

灰度发布是指在模型服务上线或更新过程中，采用渐进式、可控的方式将新版本模型逐步暴露给部分用户或流量，以验证其稳定性和效果，降低全量上线带来的风险。

## 大模型

### 如何使用大模型？

1. 点击左侧【BMP】，点击【模型市场】，选择需要的预训练大模型
2. 通过推理中心创建推理任务部署大模型
3. 部署成功后通过体验中心或 API 调用使用大模型

### 大模型微调流程是什么？

1. 准备微调数据集
2. 从模型市场选择基础模型
3. 创建大模型微调任务，配置参数
4. 启动微调任务
5. 微调完成后导出微调后的模型

## 常见问题排查

### GPU 资源不足怎么办？

- 等待其他任务释放 GPU 资源
- 联系管理员切换到其他资源组
- 减少任务所需的 GPU 数量

### 任务状态显示 Pending 是什么意思？

Pending 表示任务正在排队等待资源分配。通常是因为当前资源组的 GPU 资源已被占用，需要等待其他任务完成释放资源。
