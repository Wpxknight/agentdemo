### 推理中心

#### 在线推理

**功能说明：**在线推理是指将训练好的机器学习模型部署在线上服务环境中，实时处理用户请求并返回预测结果的过程。当用户通过应用程序发起请求时，系统会实时调用已部署的模型，输入当前数据，模型在毫秒级时间内进行计算，并即刻返回推理结果。在线推理是模型投入生产使用的核心环节，要求具备高可用、低延迟和弹性扩展能力，以支撑实际业务场景的实时决策需求。

#### 批量推理

**功能说明：**批量服务可对批量数据进行推理，完成数据处理后自动停止，支持部署任务的新建，列表，部署状态，部署日志查看；新建批量预测，支持选择某个模型部署，支持选择输入批量预测数据集，支持选择输出批量预测结果；支持批量预测任务详情查看。
**操作说明：**点击左侧【BMP】，点击【推理中心】，点击【批量推理】，可查看所有批量推理任务

#### API key管理

**功能说明：**API key 是用于身份验证和授权的一串唯一代码（通常为字符串形式），当客户端调用 API 时需在请求中提供此密钥。服务端通过验证 API key 来确认调用者的合法性、追踪其使用情况，并控制访问权限（如限制可调用的 API、设定请求频率或用量配额）。其主要功能包括：确保 API 仅被已授权的用户或应用访问、保障服务安全、防止滥用，并常用于进行计费或使用量统计。（备注：暂不支持项目隔离）

#### 13.3 灰度发布

**功能说明：**灰度发布是指在模型服务上线或更新过程中，采用渐进式、可控的方式将新版本模型或服务逐步暴露给部分用户或流量，以验证其稳定性和效果，降低全量上线带来的风险 。这种策略广泛应用于机器学习模型推理服务部署中，尤其在云原生和微服务架构下，成为保障服务高可用性和持续交付的关键实践之一。
